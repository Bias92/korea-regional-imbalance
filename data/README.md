# 데이터 관리

이 폴더는 대시보드에 사용하는 원본 데이터와 전처리 결과를 관리한다.

## 구조

- `raw/`: KOSIS, 행정안전부, 교육부 등에서 내려받은 원본 CSV 보관
- `processed/`: 원본 CSV를 정리한 중간 산출물 보관
- `phase1-regions.json`: Phase 1 MVP 화면에서 직접 로드하는 정적 JSON
- `skorea-provinces-2018-topo-simple.json`: Phase 2 지도에 사용하는 시도 단위 TopoJSON
- `skorea-provinces-license.md`: 지도 경계 원자료 라이선스 기록

## 현재 상태

`phase1-regions.json`은 **요약 지표(summary)와 시도별 데이터(regions)의 출처 단계가 다르다.**

**summary (요약 지표 4종) — 공식 통계 교체 완료 (2026-05-29):**

| 지표 | 값 | 출처 | 기준연도 |
| --- | --- | --- | --- |
| 수도권 인구 비중 | 50.8% | 통계청 인구주택총조사(등록센서스) | 2024 |
| 수도권 GRDP 비중 | 52.3% | 통계청 지역소득(잠정) | 2023 |
| 인구감소지역 수 | 89곳 | 행정안전부 인구감소지역 지정 고시 | 2021 지정·2026 유지 |
| 폐교 수 | 3,922곳 | 교육부 지방교육재정알리미 폐교 현황 | 누계 |

각 지표 객체에 `source`, `sourceYear` 필드를 추가해 화면 카드에 출처가 직접 표시되도록 했다.
(폐교 누계는 집계 기준·시점에 따라 출처별 편차가 있어 값은 종전 수치를 유지하되 출처만 명시했다. 단일 기준연도 누계 확정은 후속 과제로 둔다.)

**regions (시도별 인구증감률·인구감소지역 수·폐교 수) — 아직 임시 시연 데이터:**

시도별 막대차트와 지도 choropleth가 읽는 값은 여전히 화면 검증용 임시 데이터다.
KOSIS 시도별 인구증감 통계와 시도교육청 폐교 현황으로 후속 교체해야 한다.

`skorea-provinces-2018-topo-simple.json`은
[`southkorea/southkorea-maps`](https://github.com/southkorea/southkorea-maps)의
KOSTAT 2018 시도 단위 TopoJSON을 저장한 것이다. 지도 경계 원자료는 통계청
통계지리정보서비스(SGIS)에서 공공누리 제1유형 라이선스로 제공된 자료이며, 원문
라이선스 문구는 `skorea-provinces-license.md`에 보관한다.

임시 데이터(regions)를 아직 사용하는 이유:

- API 키와 CORS 문제 없이 화면 구조를 먼저 검증하기 위해
- 카드와 차트 요구사항을 빠르게 테스트하기 위해
- 데이터 교체 전후의 변경 이력을 Git에 남기기 위해

## 교체 원칙

1. 공식 원본 파일을 `raw/`에 저장한다.
2. 전처리 기준을 커밋 메시지 또는 별도 문서에 남긴다.
3. 화면이 읽는 JSON 구조는 가능하면 유지한다.
4. 임시 데이터가 공식 데이터로 교체되면 `meta.status`를 갱신한다.
