# 요구사항 명세 (Phase 1)

본 문서는 Korea Regional Imbalance Dashboard의 Phase 1 MVP 요구사항을 정의한다.
요구사항은 기능 요구사항, 비기능 요구사항, 검증 기준으로 구분한다.

---

## 1. 사용자와 목표

### 주요 사용자

- 지역 불균형 문제를 빠르게 이해하려는 일반 사용자
- 소프트웨어공학 과제 평가자
- 프로젝트 진행 과정과 AI 활용 방식을 확인하려는 리뷰어

### 사용자 목표

- 수도권 집중과 지방 인구감소의 핵심 수치를 한 화면에서 파악한다.
- 시도별 인구 증감률 차이를 막대차트로 비교한다.
- 데이터 시각화 개발 과정에서 요구사항, 설계, 구현, 검증이 어떻게 연결되었는지 확인한다.

---

## 2. Phase 1 범위

### 포함

- 수도권 인구 비중 카드
- 수도권 GRDP 비중 카드
- 인구감소지역 수 카드
- 폐교 수 카드
- 시도별 인구 증감률 막대차트
- 데이터 출처와 기준연도 표시

### 제외

- 시군구 단위 choropleth 지도
- 폐교 위치 기반 지도 레이어
- 실시간 API 연동
- 사용자 계정, 저장, 공유 기능

---

## 3. 기능 요구사항

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| FR-001 | 대시보드는 핵심 통계 카드를 표시해야 한다. | 인구, GRDP, 인구감소지역, 폐교 수 카드가 한 화면에 표시된다. |
| FR-002 | 대시보드는 시도별 인구 증감률을 막대차트로 표시해야 한다. | 17개 시도 데이터가 Chart.js 막대차트에 표시된다. |
| FR-003 | 수도권과 비수도권을 시각적으로 구분해야 한다. | 수도권 지역은 데이터와 차트에서 구분 가능한 스타일 또는 라벨을 가진다. |
| FR-004 | 데이터 기준연도와 출처 상태를 표시해야 한다. | 화면 하단 또는 설명 영역에 기준연도와 임시 데이터 여부가 표시된다. |
| FR-005 | 정적 JSON 데이터를 로드해야 한다. | `data/phase1-regions.json`을 기준으로 화면이 렌더링된다. |

---

## 4. 비기능 요구사항

| ID | 요구사항 | 완료 기준 |
|---|---|---|
| NFR-001 | 정적 호스팅 가능성 | 별도 빌드 없이 브라우저에서 실행된다. |
| NFR-002 | 반응형 레이아웃 | 데스크톱과 모바일 폭에서 주요 정보가 겹치지 않는다. |
| NFR-003 | 재현성 | 데이터 파일과 화면 코드가 Git에 함께 기록된다. |
| NFR-004 | 유지보수성 | 데이터, 화면 구조, 스타일이 분리되어 있다. |
| NFR-005 | 접근성 | 카드와 차트 주변 텍스트가 충분한 대비를 가진다. |

## 6. 변경 관리

- 새 기능은 Phase 범위에 맞는 요구사항 ID를 먼저 추가한 뒤 구현한다.
- 지도, 폐교 위치 표시처럼 범위가 큰 기능은 Phase 1에 섞지 않는다.
- AI 제안으로 스코프가 바뀌면 `docs/design.md` 또는 `docs/ai-log/`에 결정 근거를 남긴다.
