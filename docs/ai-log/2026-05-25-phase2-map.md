# 2026-05-25 Phase 2 지도 초안 구현

## 작업 배경

2026-05-25는 계획상 Phase 2 시작일이다. Phase 1 MVP와 소프트웨어공학 프로세스 문서화가 완료된 뒤,
오늘의 추가 진척으로 Leaflet 기반 시도 단위 choropleth 지도 초안을 구현했다.

## 구현 내용

- `src/index.html`
  - Leaflet CSS/JS와 `topojson-client` CDN 추가
  - 시도별 인구 증감 지도 섹션 추가
  - 지도 상세 패널 추가
- `src/styles.css`
  - 지도 패널, 지도 범례, 상세 패널, 반응형 레이아웃 스타일 추가
- `src/app.js`
  - `data/skorea-provinces-2018-topo-simple.json` 로드
  - TopoJSON을 GeoJSON으로 변환
  - Phase 1 지역 데이터와 KOSTAT 지도 코드를 매핑
  - 인구 증감률 기준 색상 표시
  - 수도권 경계 강조
  - 지도 hover/click 상세 정보 표시
  - 지도 지표 전환 버튼 추가
  - 지역 선택 드롭다운 추가
- `data/`
  - KOSTAT 2018 시도 단위 TopoJSON 추가
  - 지도 경계 라이선스 문서 추가
- `tests/verify-data.mjs`
  - 지도 경계 17개와 지역 코드 매핑 자동 검증 추가

## 의사결정

외부 GeoJSON URL을 런타임에 직접 호출하지 않고, 단순 TopoJSON을 저장소에 포함했다.

근거:

- 제출 시점의 화면 재현성 확보
- 원격 파일 변경이나 네트워크 장애 리스크 감소
- 원본 GeoJSON보다 작은 파일 크기
- 데이터 출처와 라이선스 기록 용이

## 남은 리스크

- 지도 색상 기준은 임시 데이터 기준이므로 공식 통계 교체 후 재조정해야 한다.
- 모바일 지도 조작성과 브라우저 콘솔 검증은 추가 캡처가 필요하다.
- 지도 경계는 2018년 기준이므로 최신 행정구역 기준과 차이가 있는지 확인해야 한다.

## 추가 UX 보강

초기 지도 초안은 시각적으로는 보이지만 사용자가 무엇을 조작할 수 있는지 약했다.
따라서 지도 기준을 `인구 증감률`, `인구감소지역`, `폐교 수`로 전환하는 버튼과
17개 시도를 직접 선택하는 드롭다운을 추가했다.

## 추가 분석 레이어

사용자 피드백으로 "그냥 데이터만 보여주는 앱"이라는 문제가 드러났다.
이를 해결하기 위해 인구 감소 폭, 인구감소지역 수, 폐교 수를 결합한 종합 위험지수를 추가했다.

반영 내용:

- 지도 기본 지표를 위험지수로 변경
- 우선 대응 지역, 감소 신호, 수도권/비수도권 격차를 보여주는 핵심 진단 카드 추가
- 지역 상세 패널에 종합 위험지수와 위험 등급 추가
- 기존 감소 폭 상위 목록을 위험도 상위 지역 목록으로 변경
