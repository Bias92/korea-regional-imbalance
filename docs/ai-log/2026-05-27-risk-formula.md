# 2026-05-27 위험지수 산식 설명 UI 추가

## 작업 배경

사용자 피드백에서 데모가 "그냥 데이터를 보여주는 앱"처럼 보인다는 문제가 반복적으로 나왔다.
전날 위험지수 시나리오와 지역 비교 기능을 추가했지만, 점수가 어떤 기준으로 계산되는지 화면에서
바로 설명되지 않으면 분석 기능의 설득력이 약하다.

## 구현 내용

- 핵심 진단 영역에 위험지수 산식 패널 추가
- 선택된 시나리오의 가중치 텍스트 표시
- 인구 감소, 인구감소지역, 폐교 수 가중치 바 표시
- 시나리오 버튼 전환 시 산식과 가중치 바 동시 갱신
- 요구사항, 설계 결정, 테스트 계획, 회고 문서 갱신

## 검증

```bash
node --check src/app.js
node tests/verify-data.mjs
python -m json.tool data/phase1-regions.json
python -m json.tool data/skorea-provinces-2018-topo-simple.json
```

브라우저 확인 항목:

- 위험지수 산식 패널 표시
- 균형 기준 산식 기본 표시
- 폐교 중심 시나리오 선택 시 폐교 수 55% 산식 표시
- 요소별 가중치 바 3개 표시

## 남은 리스크

- 현재 산식은 임시 데이터 기반 가설 지표다.
- 공식 데이터 교체 후 정규화 기준, 가중치, 등급 구간을 다시 검토해야 한다.
- 최종 보고서에는 위험지수가 정책 판단 보조 지표이며 절대 평가가 아님을 명시해야 한다.
