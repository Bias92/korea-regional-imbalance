# 2026-05-29 요약 지표 공식 통계 교체

## 작업 배경

`data/README.md`와 최근 회고에서 가장 큰 미해결 과제로 반복 지적된 것이
"임시 시연 데이터 → 공식 통계 교체"였다. Phase 1·2 화면 구조와 위험지수·시나리오·
비교 기능은 충분히 갖춰졌지만, 화면에 박힌 숫자가 임시값이고 출처가 없으면
대시보드의 신뢰성과 과제 설득력이 약하다.

데이터 전체를 한 번에 교체하면 검증 부담이 크므로, 화면 최상단에서 가장 눈에 띄고
교체 효과가 큰 **요약 지표(summary) 4종**부터 공식 통계로 교체하기로 했다.

## 의사결정

- 시도별(regions) 데이터까지 한 번에 바꾸지 않고 summary부터 분리 교체한다.
  → 변경 단위를 작게 가져가 검증 가능성과 추적성을 확보한다.
- 숫자만 바꾸지 않고 각 지표에 `source`, `sourceYear` 필드를 추가해
  화면 카드에서 출처가 직접 보이도록 한다. (데이터 시각화의 신뢰성 = 출처 표기)
- 값이 출처별로 편차가 큰 항목(폐교 누계)은 무리하게 바꾸지 않고
  값은 유지하되 출처만 명시한다. 단일 기준연도 누계 확정은 후속 과제로 분리한다.

## 교체 내용

| 지표 | 변경 전 | 변경 후 | 출처 / 기준연도 |
| --- | --- | --- | --- |
| 수도권 인구 비중 | 50.7% | **50.8%** | 통계청 인구주택총조사(등록센서스) / 2024 |
| 수도권 GRDP 비중 | 52.8% | **52.3%** | 통계청 지역소득(잠정) / 2023 |
| 인구감소지역 수 | 89곳 | 89곳(유지) | 행정안전부 인구감소지역 지정 고시 / 2021 지정·2026 유지 |
| 폐교 수 | 3,922곳 | 3,922곳(유지) | 교육부 지방교육재정알리미 폐교 현황 / 누계 |

- GRDP 비중 52.8%는 과거 연도 수치였다. 통계청 2023년 지역소득(잠정) 발표 기준으로
  수도권 GRDP 1,258조 원, 전국의 52.3%(전년 대비 0.5%p 감소)가 확인되어 교체했다.
- 인구감소지역 89곳은 행안부 최초 지정(2021.10) 이후 2026년 현재까지 유지되어 값은 정확했고,
  출처만 보강했다.

## 구현 내용

- `data/phase1-regions.json`
  - `meta.status`를 `prototype-sample` → `summary-official-mixed`로 변경
  - `meta.warning`을 "summary는 공식 통계 교체 완료, regions는 임시"로 명확화
  - summary 4개 지표에 `source`, `sourceYear` 필드 추가 및 값 갱신
- `src/app.js`
  - `renderSummary`에서 각 카드 하단에 출처 줄(`metric-source`) 렌더링 추가
  - `source` 필드가 없는 데이터와도 호환되도록 옵셔널 처리
- `src/styles.css`
  - `.metric-source` 스타일 추가 (캡션보다 작고 흐린 출처 표기, 상단 구분선)
- `data/README.md`
  - "현재 상태"를 summary(공식)·regions(임시) 2단계로 재정리

## 검증

```bash
python3 -m json.tool data/phase1-regions.json   # JSON 유효성
node --check src/app.js                          # 문법
node tests/verify-data.mjs                       # 데이터 구조 검증
```

세 가지 모두 통과. `verify-data.mjs`는 summary 항목의 label/value/unit 타입만 검사하므로
`source`, `sourceYear` 필드 추가와 값 교체 모두 기존 테스트와 호환됨을 확인했다.

브라우저 확인 항목:

- 요약 카드 4개에 출처 줄이 표시되는지
- 수도권 인구 비중 50.8%, GRDP 비중 52.3%로 표시되는지

## 남은 리스크

- regions(시도별) 데이터는 여전히 임시값이다. 막대차트·지도·위험지수 입력값이
  공식 통계로 바뀌기 전까지 위험지수 순위는 잠정 결과다.
- 폐교 누계는 집계 기준(보유폐교/종결폐교 포함 여부, 시점)에 따라 출처별로 값이 달라
  단일 기준연도 누계 확정이 필요하다.
- 최종 보고서에는 요약 지표는 공식 통계, 시도별 지표는 잠정 데이터임을 구분해 명시해야 한다.
