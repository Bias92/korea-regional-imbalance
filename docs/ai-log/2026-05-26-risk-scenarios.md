# 2026-05-26 위험지수 시나리오 기능 추가

## 작업 배경

전날 구현한 위험지수는 "데이터를 보여주는 앱"에서 "판단을 돕는 앱"으로 나아가는 첫 단계였다.
하지만 하나의 고정 산식만 제공하면 사용자가 분석 기준을 바꿔 볼 수 없고, 점수의 설득력도 약하다.

따라서 2026-05-26 작업은 위험지수를 시나리오별로 비교할 수 있게 만드는 데 집중했다.

## 구현 내용

- 핵심 진단 영역에 분석 기준 버튼 추가
  - 균형
  - 인구감소 중심
  - 소멸위험 중심
  - 폐교 중심
- 시나리오별 위험지수 가중치 적용
- 시나리오 전환 시 다음 요소를 함께 갱신
  - 핵심 진단 카드
  - 위험도 상위 지역 목록
  - 위험지수 지도 색상
  - 지도 툴팁
  - 지역 상세 패널 위험지수와 순위

## 검증

```bash
node --check src/app.js
node tests/verify-data.mjs
```

브라우저에서 확인한 항목:

- 위험지수 시나리오 버튼 4개 표시
- 지도 지표 버튼 4개 표시
- 폐교 중심 시나리오 선택 시 안내 문구 변경
- 전남 선택 시 위험지수와 위험도 순위 표시
- 브라우저 콘솔 오류 없음

## 남은 리스크

- 위험지수 산식은 임시 시연 데이터 기반 가설이다.
- 공식 데이터 교체 후 가중치와 등급 구간을 다시 검토해야 한다.
- 최종 보고서에는 위험지수 산식이 "분석 편의를 위한 파생 지표"임을 명시해야 한다.

## 추가 기능: 지역 비교 모드

사용자 피드백으로 "기능이 별로 없고 보여주기만 하는 것 같다"는 문제가 다시 드러났다.
이에 따라 두 지역을 직접 선택해 비교하는 기능을 추가했다.

반영 내용:

- 지역 A, 지역 B 선택 드롭다운
- 위험지수 차이 카드
- 인구 흐름 차이 카드
- 인구감소지역 수와 폐교 수 차이 카드
- 위험지수 시나리오 전환 시 비교 결과도 함께 재계산
