## 남은 리스크

- 현재 데이터는 공식 통계가 아닌 임시 시연 데이터다.
- Phase 1 완료 전 공식 원본 CSV 확보와 JSON 교체가 필요하다.
- 모바일 화면은 추가 캡처로 텍스트 겹침 여부를 한 번 더 확인해야 한다.

## 의사결정 메모

로컬 파일을 직접 여는 방식은 브라우저의 `fetch` 제한에 걸릴 수 있다.
따라서 로컬 검증은 정적 서버 실행을 기준으로 문서화했다.
