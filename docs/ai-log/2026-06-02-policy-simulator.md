# 2026-06-02 정책 대응 시뮬레이터 추가 로그

## 배경

데모 확인 과정에서 "지도와 데이터만 보여주는 앱처럼 보인다"는 문제가 제기되었다.
기존 대시보드는 위험지수, 지도, 지역 비교, 대응 전략 브리프를 제공했지만 사용자가 직접
정책 가정을 조정해 결과 변화를 확인하는 기능은 부족했다.

## AI와의 토의 요약

- 단순 기능 추가보다 사용자 조작성이 드러나는 기능이 필요하다고 판단했다.
- 위험지수 산식을 새로 만들지 않고 기존 시나리오 가중치와 위험 구성요소를 재사용하기로 했다.
- 정책 패키지는 청년·일자리, 생활권 인프라, 폐교 활용 세 가지로 제한했다.
- 결과에는 예상 위험지수 변화뿐 아니라 집중 패키지, 잔여 리스크, 실행 순서를 함께 표시하기로 했다.
- 시도별 데이터가 아직 임시값이므로 화면 안내와 보고서 요약에 "정책 가설"임을 명시하기로 했다.

## 반영 사항

- `FR-025` 요구사항 추가
- Policy Lab 영역 추가
- 정책 패키지 슬라이더 3종과 대상 지역 선택 추가
- 현재 위험지수 시나리오 기준으로 예상 위험 변화를 재계산
- 보고서 요약 Markdown에 정책 시뮬레이션 가설 포함
- UI 계약 검증에 시뮬레이터 DOM과 함수 연결 추가

## 교훈

바이브코딩은 새 화면을 빠르게 붙이는 데 강하지만, 그 기능이 왜 필요한지 문서와 테스트에 연결하지
않으면 단순한 즉흥 구현처럼 보일 수 있다. 이번 변경은 사용자 피드백을 요구사항으로 환원하고,
설계 결정, 구현, 검증, 회고에 연결한 사례로 기록한다.
