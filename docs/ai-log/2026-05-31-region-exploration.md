# 2026-05-31 지역 탐색과 대응 전략 보강

## 작업 배경

Phase 2 마감일 기준으로 지도, 시나리오, 비교, 산식 설명은 갖춰졌지만 사용자가 데모에서
"무엇을 직접 해볼 수 있는가"는 더 강화할 여지가 있었다. 특히 지역 목록은 위험도 상위 지역만
고정으로 보여줘 탐색 기능이라기보다 요약 표시 영역에 가까웠다.

## 구현 내용

- 지역 탐색 기능 추가
  - 지역명 검색
  - 수도권/비수도권 필터
  - 위험지수, 인구 감소, 인구감소지역, 폐교 수 정렬
- 대응 전략 브리프 추가
  - 선택 시나리오 기준 최상위 위험 지역 표시
  - 위험지수 주요 기여 요인 계산
  - 후속 검증 과제 안내
- UI 계약 검증 테스트 추가
  - 핵심 DOM id 존재 확인
  - 위험지수 시나리오 버튼 4개 확인
  - 지도 지표 버튼 4개 확인
  - 새 렌더링 함수 연결 확인

## 검증

```bash
node --check src/app.js
node tests/verify-data.mjs
node tests/verify-ui-contract.mjs
python -m json.tool data/phase1-regions.json
```

브라우저 확인 항목:

- 지역 검색 입력 시 목록 필터링
- 비수도권 필터 적용
- 폐교 수 정렬 적용
- 폐교 중심 시나리오 선택 시 대응 전략 브리프 갱신

## 남은 리스크

- 시도별 인구 증감률과 폐교 수는 아직 임시 데이터다.
- 최종 보고서에는 "요약 지표는 공식, 시도별 분석은 잠정"이라는 데이터 상태를 분리해서 설명해야 한다.
- Phase 3에서는 폐교 통계 기준연도와 시도별 공식 데이터를 우선 확정해야 한다.
